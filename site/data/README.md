# Deployment data snapshot

This directory contains the selected Korean Arknights game-data snapshot used as build input.

- Upstream: `ArknightsAssets/ArknightsGamedata`
- Region: `kr`
- Source commit: `758c9e70c34aa56cb8e04dd84b40440c5c859a67`
- Retrieved from: `data/raw/arknights-gamedata`

The files are not served directly. The build script reads them and generates the archive index used by the explorer.
