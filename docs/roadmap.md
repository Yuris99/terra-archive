# Terra Archive 작업 순서

현재 목표는 출처를 확인할 수 있는 다국어 세계관 검색과 RAG입니다. 작업 전에는 목적과 완료 기준을 설명하고, 작업 후에는 실제 결과·검증·한계를 이 문서와 진행 기록에 남깁니다.

| 단계 | 하는 일 | 완료 기준 | 상태 |
| --- | --- | --- | --- |
| 0. 자료 수집 | 한국어 TXT 및 4개 언어 JSON·관련 테이블 확보 | 출처 커밋 고정, JSON·해시·회상 색인 검사 | 완료 |
| 1. 정규화 | 대사·지문·선택지·프로필·음성·모듈·스킨을 공통 문서로 변환 | 순서·화자·언어·원본 위치 보존, 문서 ID 중복·내용 누락 검사 | 완료 |
| 2. 검색 단위 만들기 | 긴 문서를 문맥을 유지하는 작은 묶음으로 나누기 | 분기 명령 경계 분리·조건 보존, 긴 문장·동영상 장면 처리, 원문 위치 연결 | 완료: 206,048개 |
| 3. 본문 검색 | 검색어로 실제 대사와 설정 찾기, 언어별 같은 스토리 조회 | 예제 검색, 한국어 보완 자료·원문/언어판 비교 화면 연결 | 완료: 문자 일치 검색 |
| 4. 의미 검색 평가 | 표현이 달라도 관련 자료를 찾는 검색 추가 | 준비한 질문에 대해 단순 검색과 검색 품질 비교 | 완료: 로컬 혼합 검색, 개발 질문 20개 평가 |
| 5. RAG | 찾은 자료로 답변하고 출처 표시 | 근거 없는 주장을 구분, 언어·버전 차이와 스포일러 범위 처리 | 질문 기반 혼합 검색 연결, 인용 검사, 해석 미검증 |
| 선택 기능 | 인물·종족·조직·주제 태그 | 필요성이 확인되면 별도 작업 | 보류 |
| 로컬 미디어 | 원본 이미지·음성 연결, 중복 저장 공간 정리, 한국어 이미지 보완 | 원본 보존, 공개 범위 유지, 화면·재생 확인 | 완료: 2026-10-12, [미디어 안내](media.md) |

## 정규화 단계의 완료 기록

1단계 정규화를 완료했습니다. 수집한 ASTR 스토리 JSON 7,768개와 각 언어의 프로필·음성·모듈·스킨 테이블을 공통 형식으로 변환했습니다. 총 문서 105,101개와 본문 항목 1,694,340개를 원본 필드와 대조했습니다. 기존 한국어 TXT는 비교용 원본으로 유지합니다.

이번 단계에서는 원문의 항목을 추출하고 같은 자료의 언어별 연결 후보를 만들었습니다. 문장 단위 번역 정합성, 의미 검색, AI 답변 기능은 각 후속 단계에서 검증합니다.

## 완료한 검색 단위 만들기와 화면 연결

입력은 전체 보관본이 아니라 `data/retrieval/global-v1/`의 검증된 글로벌 범위 선택본으로 제한합니다. 글로벌 미출시 항목을 청크로 만든 뒤 화면에서 숨기는 방식은 사용하지 않습니다. 이미 출시된 콘텐츠의 언어판 차이는 유지하고, 같은 경로의 `annotations.json`에 있는 표시를 해당 청크의 원문 위치에 연결합니다.

주변 대사와 화자 정보를 유지하며 목표 900자·최대 1,400자 기준으로 묶었습니다. 원본 문서 ID·본문 항목·원문 문자열 범위를 남겨 원문을 복원하고 언제든 원문으로 돌아갈 수 있게 했습니다. 글자 수 기준은 토큰 수가 아니며 언어별 검색 품질에 따라 추후 조정할 수 있습니다.

완료 기준은 본문을 누락 없이 포함하는지, 서로 다른 선택지의 결과를 같은 대화로 섞지 않는지, 긴 프로필과 언어별 길이 차이를 처리하는지입니다. 본문이 없는 동영상 장면은 목록에 남기되 검색용 본문을 만들어내지 않습니다. 같은 스킨 문구의 반복도 이 단계에서 검색 중복 처리 기준을 정합니다.

문서 103,668개에서 청크 206,048개를 만들고 전체 재읽기 대조를 통과했습니다. 본문 없는 3,288개는 문서 목록에 보존하고 청크를 만들지 않았습니다. 새 `/search` 화면에서 본문 검색·원문·언어판·알려진 차이 표시를 볼 수 있습니다. 전체 분기 경로와 문장 단위 번역 대응을 보장하지 않습니다.

## 완료한 의미 검색과 다음 작업

설치된 로컬 모델을 사용해 단어 검색 기반 RAG 시제품을 먼저 연결했습니다. 인용이 원문에 존재해도 AI가 의미를 잘못 해석할 수 있음을 실제 시험에서 확인했습니다. 따라서 기본 표시는 원문 인용이며 AI 해석은 미검증 상태로 접어 둡니다.

2026-10-03에 공식 Qwen3-Embedding-0.6B 로컬 모델을 명시 설치하고 206,048개 청크의 벡터 생성·출처 연결 검사를 마쳤습니다. 개발용 질문 20개(8개 사실 묶음)의 기대 근거 상위 5개 적중은 수동 핵심어 검색 17개, 의미만 비교 12개, 의미·단어 혼합 19개입니다. 단어 검색에 질문 문장을 그대로 넣으면 0개였으나 기존 기능이 고장났다는 뜻은 아닙니다. 혼합이 이 세트에서는 표현 차이와 특정 인물·제목 단서를 보완했습니다.

다음은 개발 중 보지 않은 질문, 여러 장면을 종합하는 질문, 답이 없는 질문에서 검색과 답변 의미 정확성을 별도로 평가하는 것입니다. 이번 결과를 일반 정답률로 읽지 않습니다. 글로벌 보류는 그대로이며 주제 태그도 계속 보류합니다. 자동 다운로드·유료 API·외부 공개는 하지 않았습니다. 자세한 결과는 [의미 검색 안내](semantic-search.md)에 있습니다.

2026-10-04에 검색 서버를 다시 켜고 기존 설정으로 5문항 RAG 실행을 완료했습니다. 긍정 질문 4개는 기대 출처를 인용했고 자료에 없는 질문은 거절했습니다. 수동 원문 대조에서는 3개 설명이 지지됐고 영어 캔디 답변의 인물·발언 연결 표현 1개는 보완이 필요했습니다. 따라서 RAG 전체를 완료로 올리지 않습니다. 다음 우선순위는 인물 메타데이터와 실제 발언자 구분·부정·잘못된 전제 검사이며, 그 뒤 처음 보는 질문과 여러 장면 종합 평가로 확대합니다. 측정과 설명은 [의미 검색 안내](semantic-search.md)에 있습니다.

## 공부할 때 잡을 핵심 개념

- **수집**: 외부 자료를 내려받고 버전을 기록하기.
- **정규화**: 서로 다른 입력 형태를 공통 구조로 바꾸기. 내용을 요약하거나 잘라내는 작업과 구분합니다.
- **청킹**: 검색에 사용할 크기로 문서를 묶거나 나누기.
- **검색**: 질문에 필요한 근거를 찾기.
- **임베딩**: 의미가 가까운 자료를 찾기 위해 내용을 숫자로 표현하기.
- **RAG**: 검색한 근거를 모델에 전달하고 그 근거에 기반해 답변하기.
- **태그**: 검색·필터에 활용할 분류 정보. RAG의 필수 조건은 아닙니다.

상세 결과와 실제로 부딪힌 문제는 [진행 기록](progress-log.md)에 남깁니다.

## 2026-10-02 — 글로벌 범위만 사용하기로 결정

사용자 결정은 **글로벌 서버에 아직 출시되지 않은 콘텐츠를 제외**하는 것입니다. 중국어 전체나 출시된 이야기의 언어판 차이를 제거하는 결정은 아닙니다. 한·중·일·영 공통 자료의 중국어판은 유지합니다. 출시된 콘텐츠의 중국어 단독 문장은 삭제하지 않고 언어판 차이로 표시합니다.

영어 기준 자료에 한국어·일본어 대응 키까지 있는 항목만 허용하고, 글로벌 테이블에 기록된 미래 최초 공개일도 차단합니다. 대응 자료가 없는 항목은 출시 여부 확인 전 보류하며 미출시 확정으로 단정하지 않습니다. 원본과 전체 정규화 자료는 로컬 보관용이며 검색에서는 사용하지 않습니다.

이번 수집본에서 글로벌 대응이 없는 1,433개를 제외했습니다. 검증된 선택본에는 문서 103,668개와 본문 항목 1,669,670개가 있습니다. 이 선택본만 청킹·본문 검색·로컬 RAG에 연결했습니다. 이 수량은 실시간 글로벌 공개 판정이나 문장 단위 번역 검증을 뜻하지 않습니다.

사용자가 기준을 명확히 한 뒤 「동화의 서막」의 중국어 단독 문장 1개에 보존용 표시를 추가했습니다. 원문은 유지하고 표시를 청크·원문 화면·RAG 근거에 연결했습니다. 화자·선택지 품질 문제는 추측해 고치지 않았고, 알려진 선택지 수 불일치를 청크와 화면에서 경고합니다.

### 보류 유지에 대한 사용자 확인

사용자는 제시된 스토리 목록이 아직 글로벌에 나오지 않은 콘텐츠임을 확인하고 당분간 보류하도록 지시했습니다. 기존 보류 목록과 검색용 선택본은 그대로 유지합니다. 메인 17장이 곧 출시 예정이라는 사용자 정보를 기록하되, 예정만으로 검색 범위를 해제하지 않습니다.

메인 17장 등 보류 콘텐츠는 실제 글로벌 출시가 확인된 뒤 글로벌 수집본과 공개 기준일을 검토하고 범위 선택·검증을 다시 실행해 포함 여부를 결정합니다. 구체적인 출시일이나 나머지 항목의 상태를 이번에 독립 확인한 것은 아닙니다.

## 2026-10-04 — 답변 품질 단계의 갱신

기존 5문항과 새 질문 10개를 개발 9개·독립 6개로 나눠 검사했습니다. 제목/관련 인물과 발언자를 구분하는 일반 지시·근거 형식을 적용했고 원래 영어 맛 질문의 근거 없는 인물 표현은 빠졌습니다. 선택한 보완안은 15/15 응답, 기대 원문 상위 5개 13/13, 정확한 인용 14개, 근거 없는 질문 2개 모델 자체 보류입니다.

설명 전체 수동 대조는 11개 지지·4개 보완 필요입니다. 한국어 호칭의 화자 추측·모형총의 인용 실패·출신지와 일본어 미래 질문의 답변/한계 모순이 남아 **RAG 품질 완료로 올리지 않습니다.** AI 한계 설명도 접고 미검증으로 표시했지만 오류가 해결됐다는 뜻은 아닙니다.

자동 테스트 71개·HTTP 17건·린트·새 빌드와 서버 재시작을 확인했습니다. 다음은 화자 근거 확인·답변/불확실성 일관성·정확한 인용 생성 검사이며 여러 장면 종합은 그 뒤입니다. 원문·검색 정책·보류·주제 태그 보류를 유지합니다. 상세 내용은 [의미 검색 안내](semantic-search.md)와 [진행 기록](progress-log.md)에 있습니다.
