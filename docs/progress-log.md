이번 구현에서는 전체 본문과 출처를 보존하고, 선택지·분기·동영상 정보를 별도로 남깁니다. 형식과 재실행 방법은 [정규화 스키마](normalized-schema.md), 다음 단계는 [작업 순서](roadmap.md)에 기록합니다.

### 어떻게 검증했나

9개의 자동 테스트를 통과했습니다. 서식 제거, 원본 위치, 화자·순서, 선택지 분기, 동영상 전용 장면, 프로필 변형, 추가 음성, 기본 증표, 스킨 필드를 확인했습니다. 일부 테스트에서는 일부러 문장을 줄이거나 화자·분기 대상을 바꾸어 검사기가 오류를 잡는지도 확인했습니다.

그다음 변환 함수를 호출하지 않는 별도 검사기로 전체 산출물을 원본과 대조했습니다.

- 입력 파일 7,820개(스토리 7,768개 + 보조 파일 52개)의 해시를 확인했습니다.
- 원본에서 추출 대상인 본문 필드 1,694,340개가 각각 정확한 위치·순서·화자로 변환됐는지 확인했습니다.
- 모든 문서 ID의 유일성과 언어별 연결 목록, 출력 파일의 수량·해시를 검사했습니다.
- 한국어 회상 색인 1,909편을 4개 언어 모두에서 확인했습니다.
- 「불을 쫓는 낙엽」 19편과 「오랜만」 6편이 모두 정규화됐습니다.
- 본문이 없는 스토리는 언어별 1개이며, 모두 같은 동영상 전용 장면입니다.

전체 검사 결과는 **통과, 오류 0개**입니다. 확인 범위는 이번에 확보한 ASTR JSON과 지정된 테이블 필드입니다. 게임의 모든 텍스트나 변환 전 TXT와의 완전한 일치까지 보증한 것은 아닙니다.

산출물은 `data/normalized/v1/`에 있으며 약 516 MB입니다. 게임 텍스트가 담긴 산출물은 Git에서 제외하고, 원본은 그대로 유지했습니다. 수량은 [생성 보고서](../data/reports/normalization.json), 검사 결과는 [검증 보고서](../data/reports/normalized-validation.json)에 남겼습니다. 재실행 방법은 [README](../README.md#공통-문서-변환-및-검증)에 있습니다.

### 이번에 배운 점

**1. 정규화는 의미를 추측하는 분류와 다릅니다.**

지금은 파일에서 확실히 알 수 있는 언어·자료 종류·화자·출처를 정리했습니다. “살카즈 이야기” 같은 주제 판단은 하지 않았습니다. 주제 태그를 보류해도 검색 근거를 준비할 수 있습니다.

**2. 원본 위치가 있어야 나중에 답변의 근거를 보여줄 수 있습니다.**

본문만 복사하면 어느 버전의 어느 대사인지 놓치기 쉽습니다. 저장소 커밋은 자료 버전, 파일 경로는 자료 위치, JSON Pointer는 파일 내부 위치를 가리킵니다. 원본 해시는 파일이 바뀌었는지 확인하는 지문 같은 역할을 합니다.

**3. 꺾쇠로 둘러싼 문자열이 모두 서식은 아닙니다.**

실제 영어 자료에는 `<Active Originium>` 같은 시설 명칭이 있습니다. 모든 `<…>`를 지우면 이 내용까지 사라집니다. 실제로 확인한 서식 태그만 제거하고 명칭·책 제목과 닉네임 변수는 남기도록 구현했습니다. 이 구분도 테스트에 넣었습니다.

**4. 표시 요소 이름과 대사 화자는 구분해야 합니다.**

`animtext`의 `name`은 캐릭터가 아니라 화면 글의 표시 요소 이름일 수 있습니다. 이를 화자로 처리하면 존재하지 않는 인물이 말한 것처럼 검색될 수 있어, 실제 대사 형식에서만 화자를 가져옵니다.

**5. 선택지 뒤의 내용을 한 줄로 이어 붙이면 맥락이 왜곡될 수 있습니다.**

선택지 A와 B의 결과는 다른 경로입니다. 이번에는 분기 정보를 보존했고, 다음 청킹 단계에서는 서로 다른 경로가 같은 대화로 묶이지 않게 해야 합니다.

### 아직 하지 않은 것과 다음 순서

청킹, 본문 검색, 임베딩, RAG 답변, 주제 태그는 아직 구현하지 않았습니다. 기존 탐색기 UI도 수정하지 않았으므로 보완 25편이 바로 화면에 나타나는 상태는 아닙니다.

다음은 **청킹**입니다. 지금의 공통 문서를 검색하기 좋은 크기로 묶되 화자·주변 문맥·분기·원본 위치를 유지합니다. 이후 본문 검색을 붙이고 실제 질문으로 검색 품질을 평가한 뒤 RAG 답변을 구현합니다.

## 2026-10-02 — 글로벌 미공개 내용 제외

사용자가 “아직 글로벌 서버에 안 나온 내용은 제외”하기로 결정했습니다. 중국어 번역 자체는 유지하고 미공개 범위만 제외합니다. 초기의 중국어 전용 자료 보관과 실제 검색에 쓸 범위는 별개로 취급합니다.

### 구현한 기준과 결과

`config/retrieval-policy.json`에 보호 기준을 기록했습니다. 영어 자료를 기준으로 한국어·일본어에도 대응 자료 키가 있어야 포함합니다. 글로벌 스토리·모듈·스킨 테이블에 미래 최초 공개일이 있으면 같은 자료의 모든 언어판을 제외합니다. 미래 복각일은 이미 공개된 자료를 차단하는 근거로 사용하지 않습니다.

이번 수집본에서 글로벌 대응이 없는 스토리 100개, 프로필 160개, 음성 844개, 모듈 39개, 스킨 290개를 제외했습니다. 합계는 1,433개이며 현재는 모두 중국어 단독 항목입니다. 명시된 미래 최초 공개일 때문에 추가로 제외된 항목은 없었습니다.

검색용 선택본에는 문서 **103,668개**, 본문 항목 **1,669,670개**가 남았습니다. 연결 키는 25,917개이고, 스토리는 언어별 1,917개입니다. 선택 출력은 `data/retrieval/global-v1/`, 결과는 [글로벌 범위 검사 보고서](../data/reports/global-selection.json)에 있습니다. RAW와 전체 정규화 자료는 삭제하지 않았습니다.

### 검증과 학습 포인트

자동 테스트는 기존 9개와 새 범위·출력 검사 10개를 합쳐 **19개 모두 통과**했습니다. 중국어 전용 항목, 글로벌 일부 언어만 있는 항목, 미래 공개일, 알 수 없는 ID를 차단하는지 확인했습니다. 일부러 선택 본문을 바꾸고 해시를 다시 계산해도 원문 동일성 검사에서 실패하는지 확인했습니다.

출력 전체를 다시 읽어 허용된 ID만 들어 있는지, 모든 허용 문서가 남았는지, 출력 파일과 목록의 해시가 맞는지, 원본 문자열이 그대로 복사됐는지 검사했습니다. 결과는 **통과, 오류 0개**입니다. 재생성이 중간에 실패하면 이전 성공 표시도 유지하지 않도록 했습니다.

여기서 배운 점은 **수집한 자료의 범위와 검색에 사용하는 범위는 다를 수 있다**는 것입니다. 원본은 보존하면서 검색 입력에서 제외할 수 있습니다. 청크를 만든 뒤 화면에서 숨기면 검색 근거에 다시 섞일 수 있으므로, 청킹 전에 범위를 제한합니다.

검사 중 Windows에서 오류가 난 테스트의 파일 읽기가 닫히지 않아 임시 폴더 정리가 실패하는 문제도 발견했습니다. 검사 실패 시에도 파일을 닫도록 수정했고, 테스트에서 만든 임시 자료만 정리했습니다.

### 확인 범위의 한계

글로벌 공개분의 기준은 이번 고정 수집본의 대응 자료와 명시된 최초 공개 시점입니다. 실시간 서버 상태 인증은 아닙니다. 최초 공개일이 없는 항목은 글로벌 대응 자료의 존재를 근거로 선택합니다. 공통 자료 안에 중국어판만 추가한 문장이 있는지도 별도 언어별 검증 대상입니다. 다음 청킹 단계는 이 검증된 선택본만 사용합니다.

## 2026-10-02 — 미출시 콘텐츠와 언어판 차이를 구분하도록 정정

사용자가 “출시된 이야기의 언어판 차이는 남기고 표시하며, 제외 대상은 아직 글로벌에 출시되지 않은 콘텐츠”라고 명확히 했습니다. 중국어 단독 문장을 미출시 범위와 섞어 제외를 제안한 것은 잘못된 해석이었습니다. 해당 문장은 이전에도 삭제하지 않았으며 이번에도 본문을 그대로 유지했습니다.

「편안한 잠꼬대」 SS-8 작전 전 「동화의 서막」 중국어 원본 행 622에서 한국어·영어·일본어에 대응 문장이 없는 차이를 확인했습니다. `config/content-annotations.json`에 **언어판 차이 · 중국어 단독 문장** 표시 1개를 기록하고, 검색 선택본의 별도 `annotations.json`으로 연결했습니다. 차이의 원인은 미확인입니다. 미출시 근거로 취급하지 않습니다.

정책에 제외 범위와 언어판 차이의 보존 방침을 명시했습니다. 현재 글로벌 대응이 없는 1,433개는 수집본에 따른 **출시 여부 미확인·검색 보류** 항목입니다. 이 전체를 실제 글로벌 미출시로 독립 확인한 것은 아닙니다. 미래 최초 공개일 차단은 유지합니다.

자동 테스트 **27개 모두 통과**했고, 문서 103,668개·본문 항목 1,669,670개와 표시 1개를 다시 검사했습니다. 본문 파일 20개와 연결 목록의 해시는 적용 전과 완전히 같습니다. RAW 두 저장소도 변경되지 않았습니다. 원문이나 위치가 바뀐 표시, 제외된 문서에 대한 표시, 미출시를 허용하거나 차이를 삭제하도록 변조한 표시를 거부하는지도 테스트했습니다.
