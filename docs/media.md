# 로컬 이미지·음성

2026-10-12에 보관한 원본 미디어를 사이트에 연결했습니다. 로컬 사이트의 `/media`에서 오퍼레이터 일러스트·언어별 음성·스토리 배경과 CG·한국어 배너를 고를 수 있습니다. 기존 현황 화면의 오퍼레이터 상세와 본문 검색의 원문 읽기에도 미디어를 연결했습니다.

## 용량

EN/CN 이미지 96,774개에서 내용이 같은 37,568개를 SHA-256으로 확인하고 NTFS 하드 링크로 묶어 16,412,313,297바이트(약 16.4GB)를 확보했습니다. 경로·파일명·내용은 유지하며 압축 손실이나 해상도 축소는 없습니다. 하드 링크로 연결된 원본을 수정하면 다른 연결 경로에도 반영됩니다. 편집할 이미지는 별도 작업 파일로 복사하세요.

사이트는 원본을 스트리밍합니다. `public`에 대용량 미디어를 복사하거나 이미지 최적화 캐시를 만들지 않습니다. 미디어 파일은 Git 제외 상태입니다. 파일 탐색기의 논리 용량은 여러 경로를 각각 합산할 수 있으므로 실제 확보 공간과 다르게 보일 수 있습니다.

한국어 보완은 한국 서버 공식 CDN의 홈 배너·이벤트 표지 41개 묶음만 선택했습니다. 다운로드 31,510,809바이트, 중복 제외 PNG 216개·62,601,260바이트입니다. 전체 한국어 UI·스토리 이미지 수집 완료를 의미하지 않습니다. 버전·파일 해시·출처는 `data/raw/manifests/kr-localized-images.json`에 기록합니다. 압축 묶음은 메모리에서 처리하고 디스크에 남기지 않습니다.

## 화면 범위

기존 `global-only-v1` 선택본과 연결되는 자원만 표시합니다. 현재 기준일은 2026-10-02입니다. EN 원본의 허용 스킨 일러스트와 선택된 한국어 스토리 명령이 직접 참조하는 이미지, 선택된 음성 대사 키에 해당하는 원본 음성을 연결합니다. 파일 이름만으로 출시를 추정해 CN 자료를 추가하지 않습니다. 한국 서버 이미지도 배포 파일에 들어 있다는 이유만으로 공개하지 않습니다. 기존 공개 스토리에 연결된 표지·메인 배너 43개만 화면에 표시합니다. 가챠·상점·연결 불명 자료는 로컬 보관합니다.

| 연결 대상 | 수량 |
| --- | ---: |
| 오퍼레이터 | 415명 |
| 일러스트 | 1,273개 |
| 음성 파일 | 64,228개 |
| 이미지가 연결된 스토리 | 1,909편 |
| 스토리에 연결된 서로 다른 이미지 | 2,385개 |
| 화면의 한국어 이미지 | 43개 |

음성은 한국어 15,178개·일본어 16,121개·영어 15,178개·중국어 15,509개·지역 음성 2,242개입니다. 표시 대사는 한국어 수집본이며 음성 언어에 따라 표현이 다를 수 있습니다. 없는 파일을 다른 대사로 대체하지 않습니다.

스토리 `Background`·`Image`·`Character` 명령에서 파일이 없거나 이름이 다른 고유 참조 1,372개는 추측해 연결하지 않았습니다. 8편은 연결된 이미지가 없습니다. 게임의 연출·영상·Live2D 재현 기능은 포함하지 않습니다. 스토리 이미지 자체에 해당 이야기 내용이 포함될 수 있습니다.

## 목록 다시 만들기

저장소 루트에서 다음 명령을 실행합니다. 원본 자료와 검증된 글로벌 선택본이 있어야 합니다.

```powershell
node --preserve-symlinks --preserve-symlinks-main scripts/build-media-index.mjs
```

목록은 Git에서 제외된 `data/indexes/media-v1/index.json`입니다. 공개 정책 또는 선택본이 바뀌면 기존 목록의 제공을 중단하므로 새 목록을 생성해야 합니다. 미디어 API는 임의 경로 대신 이 목록의 ID만 받으며, 원본 폴더 밖의 경로를 거부합니다. MP3는 구간 요청과 HEAD 요청을 지원합니다.

한국어 이미지를 갱신하려면 UnityPy를 프로젝트 전용 폴더에 설치하고 수집 스크립트를 실행합니다.

```powershell
python -m pip install --no-cache-dir --target .cache/terra-media/python UnityPy==1.25.4
python -X utf8 scripts/acquire-kr-images.py
python -X utf8 scripts/acquire-kr-images.py --apply
```

첫 실행은 용량 조회만 합니다. `--apply`는 다운로드 64MiB·추출 PNG 512MiB 한도와 디스크 여유를 검사합니다. 기존 완료 버전은 이미지 해시를 확인한 뒤 다시 다운로드하지 않습니다. 전용 압축 처리의 형식 참고는 [MooncellWiki UnityPy 변경](https://github.com/MooncellWiki/UnityPy/commit/781badde6d636f101279fef76f461bb8dd0e1ffc)입니다.

중복 정리는 다음 명령으로 미리 확인할 수 있습니다. `--apply`를 붙일 때만 파일 저장 방식을 바꿉니다. 중단된 교체는 백업에서 복구하며 심볼릭 링크가 포함된 경로는 거부합니다.

```powershell
node --preserve-symlinks --preserve-symlinks-main scripts/deduplicate-media.mjs
```

## 검증

미디어 관련 자동 검사 5개, 린트, 프로덕션 빌드를 통과했습니다. HTTP 검사는 원본 바이트·PNG/MP3 종류·구간 요청·HEAD·잘못된 범위·공개 범위 밖 및 경로 요청 거부를 확인합니다. 실제 Chrome에서 일러스트와 스토리 CG·한글 배너 표시, 한국어 음성 재생을 확인했습니다. GitHub 업로드 대상은 코드·출처 목록·문서·검증 기록이며 대용량 원본과 로컬 미디어 색인은 Git에서 제외합니다. 다른 PC에서 미디어를 보려면 원본을 준비하고 목록을 생성해야 합니다. 외부 웹사이트 배포는 별도입니다.
