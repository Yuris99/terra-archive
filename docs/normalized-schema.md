# 정규화 문서 v1

## 입력과 출력

입력은 `data/raw/arknights-story-json`의 고정 커밋입니다. ASTR 변환 스토리 JSON과 4개 텍스트 테이블을 사용하고, 캐릭터·회상 색인으로 기본 정보를 보완합니다. 변환 전 스토리 TXT 커밋은 확인되지 않았으므로 출처에 이를 명시합니다.

출력은 `data/normalized/v1/<locale>/<kind>.jsonl`입니다. 한 줄에 한 문서를 저장하는 JSONL을 사용해 전체 자료를 메모리에 올리지 않고 순차적으로 처리할 수 있게 합니다. 전체 문서를 잇는 목록은 `catalog.json`, 출력 파일의 해시·수량은 `manifest.json`에 기록합니다. 게임 텍스트가 포함된 산출물은 Git에서 제외합니다.

## 공통 구조

| 필드 | 의미 |
| --- | --- |
| `id` | 언어까지 포함한 문서 식별자 |
| `canonicalId` | 언어를 제외한 자료 식별자. 언어별 자료를 잇는 후보 키 |
| `kind` | `story`, `profile`, `voice`, `module`, `skin` |
| `locale`, `language`, `region` | 텍스트 언어와 수집 서버 |
| `title`, `context` | 자료 제목, 스토리 묶음·캐릭터 등의 기본 정보 |
| `source` | 저장소, 커밋, 파일 경로, SHA-256, JSON Pointer |
| `segments` | 순서대로 추출한 본문 항목 |

스토리의 `canonicalId`는 공통 파일 경로를 사용합니다. 음성·모듈·스킨은 원본 키를 사용합니다. 프로필은 캐릭터·섹션·변형의 위치를 연결 후보로 삼으므로 문장이나 섹션의 번역 대응이 검증됐다는 뜻은 아닙니다.

## 본문 항목

각 항목은 `ordinal`, `kind`, `speaker`, `text`, `sourcePointer`를 가집니다. 스토리 항목에는 원본 `rowId`와 `rowType`도 기록합니다. 이름이 없는 지문에 화자를 추측해서 넣지 않습니다. `animtext`의 `name`은 화면 요소의 이름일 수 있으므로 화자에 사용하지 않습니다.

대사(`name`, `multiline`), 자막(`subtitle`), 화면 글(`sticker`, `animtext`), 선택지(`decision`)를 추출합니다. 선택지는 각 옵션·값·이동 대상과 함께 보존합니다. `predicate`와 동영상 명령 등은 별도 `controls`에 원본 위치와 함께 기록합니다. 선택지의 정답이나 실제 플레이 경로를 추정하지 않습니다.

읽기용 `text`에서는 게임의 서식 태그를 제거하고 줄바꿈을 통일하지만 문장을 요약하거나 길이를 제한하지 않습니다. 닉네임 등의 치환 변수는 원문대로 유지합니다. 가공 전 문자열은 `sourcePointer`로 원본에서 다시 확인할 수 있습니다.

서식 제거는 실제 수집본에서 확인한 소문자 `i`, `b`, `color`, `p`와 `@lv.*` 계열 등의 게임 태그만 대상으로 합니다. `<Active Originium>` 같은 명칭이나 `<I>` 같은 원문 표기는 남깁니다. HTML 엔티티는 서식 제거 후 한 번만 해석해, 원래 문자로 적힌 꺾쇠를 다시 태그로 삭제하지 않습니다.

프로필의 모든 `stories` 변형과 해금 조건을 보존합니다. 음성은 `charWords`뿐 아니라 `charExtraWords`도 포함합니다. 스킨은 `content`, `dialog`, `usage`, `description`을 각각 추출합니다. 동일한 문구도 원본 필드가 다르면 출처를 유지하며, 검색 중복 처리는 후속 단계에서 다룹니다.

동영상만 있는 스토리나 설명이 없는 스킨도 자료 목록에는 남깁니다. 본문이 없다는 상태와 파일이 누락됐다는 상태를 구분합니다.

## 검증 범위

- 입력 커밋·Git 상태·테이블 해시 확인.
- 문서 ID·파일 수·출력 파일 해시 확인.
- 추출 가능한 원본 텍스트 필드와 정규화 항목을 일대일 대조.
- 순서, 화자, 선택지 분기 정보, JSON Pointer 검증.
- 한국어 회상 1,909편과 보완 25편의 문서 존재 여부 확인.
- 4개 언어 공통 스토리와 중국어만 확보된 스토리의 수록 상태 확인.

이 단계의 언어별 연결은 자료 단위입니다. 동일 위치의 대사가 서로 번역 대응한다고 가정하지 않으며, 한국어 미확보 상태를 한국 서버 미출시로 단정하지 않습니다.

검증기는 변환 함수로 결과를 다시 만드는 방식이 아니라 원본 레코드·본문 필드를 독립적으로 열거해 문서와 대조합니다. 읽기용 문자열 변환과 JSON Pointer 해석은 단위 테스트를 거친 공통 함수를 사용합니다. 현재 검증 결과는 [검증 보고서](../data/reports/normalized-validation.json), 수량과 학습 기록은 [진행 기록](progress-log.md)에 있습니다.

## 보관본과 실제 검색 입력 구분

전체 정규화는 원본 대조용 보관본입니다. 사용자 결정에 따라 글로벌 미출시 콘텐츠는 검색 대상에서 제외하며, 실제 청킹·검색·RAG는 `data/retrieval/global-v1/`만 사용합니다. 이미 출시된 콘텐츠의 중국어 번역과 언어판 차이는 유지합니다. 글로벌 대응 자료가 없는 항목은 출시 여부 확인 전 보류이지 미출시 확정은 아닙니다.

`config/retrieval-policy.json`은 영어를 기준으로 한국어·일본어에도 같은 자료 키가 있어야 허용합니다. 명시된 미래 최초 공개일도 제외합니다. 출력의 ID·언어별 목록·파일 해시·원문 동일성을 전부 재검사하며, 선택 manifest가 검증 통과 상태인 경우에만 후속 입력으로 사용합니다. 이번 수집본의 선택 결과는 [글로벌 범위 검사](../data/reports/global-selection.json)에 기록됩니다.

이 기준은 자료 키와 글로벌 메타데이터에 근거합니다. 자료 단위 번역 대응은 후보이며, 중국어가 공통 문서 내부에 추가한 문장까지 검증됐다는 뜻은 아닙니다. 최초 공개일이 없는 항목은 글로벌 대응 자료의 존재를 근거로 선택합니다. 실시간 공개 여부 인증과 구분합니다.

## 언어판 차이 표시

`config/content-annotations.json`은 사람이 확인한 차이를 기록한 원장입니다. 출시된 콘텐츠에서 글로벌 3개 언어에 대응 문장이 없는 중국어 문장도 `locale-text-difference`로 표시하고 `retain-and-mark`로 보존합니다. `releaseStatusEvidence: false`는 이 표시 자체가 글로벌 미출시 판정의 근거가 아님을 뜻합니다.

표시는 원문 JSONL에 삽입하지 않고 `data/retrieval/global-v1/annotations.json`에 따로 저장합니다. 문서 ID, 연결 키, 언어, 원본 커밋·파일 경로·해시, JSON Pointer, 본문 문자열 해시, 읽기용 라벨을 기록하고 생성 시 실제 본문 항목 번호 `segmentOrdinal`을 연결합니다. 원본이나 문장이 달라지면 재검토를 요구합니다. 제외된 문서에 표시를 붙여 검색 범위를 우회할 수는 없습니다.

선택 manifest의 `annotations`에는 표시 파일의 경로·수량·바이트 수·해시와 원장의 해시가 있습니다. 전체 선택 검사는 표시가 남아 있는 실제 본문을 가리키는지도 확인합니다. 현재 1개의 표시가 있으며 전체 언어 차이의 전수 목록은 아닙니다. 화면 표시·청킹·RAG에 전달하는 기능은 아직 구현하지 않았습니다.
